# 우리동네 실거래 (부산·울산)

부산·울산 21개 구·군의 아파트 실거래가를 지도 개념도 + 리스트로 보여주는 웹앱입니다.
"지금 업데이트" 버튼을 누르면 국토교통부 공공데이터 API를 실시간으로 호출해 이번 달/지난 달 거래를 비교하고,
거래량(지역 크기)과 가격 상승·하락 추세(색상)를 화면에 반영합니다. 별도 데이터베이스 없이 버튼을 누를 때마다
그 시점 최신 데이터를 바로 계산해서 보여주는 방식입니다.

## 준비물

| 항목 | 용도 | 발급처 |
| --- | --- | --- |
| `MOLIT_SERVICE_KEY` | 국토교통부 아파트매매 실거래 상세 자료 API 인증키(디코딩 값) | [data.go.kr](https://www.data.go.kr/data/15126468/openapi.do) |
| `KAKAO_JS_KEY` | 지도 렌더링용 카카오맵 JavaScript 키 (현재 버전은 개념도만 쓰므로 아직 필수 아님) | [developers.kakao.com](https://developers.kakao.com/) |

`.env.local` 파일에 아래처럼 넣어주세요 (이미 넣어드린 상태입니다).

```
MOLIT_SERVICE_KEY=발급받은_디코딩_키
KAKAO_JS_KEY=발급받은_JavaScript_키
```

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속 → 첫 로딩 시 자동으로 실거래 데이터를 한 번 가져오고,
이후에는 화면 상단의 "지금 업데이트" 버튼으로 언제든 새로고침할 수 있습니다.

> **참고**: 이 프로젝트를 준비한 개발 환경(클라우드 샌드박스)은 보안상 `apis.data.go.kr`로 나가는
> 네트워크가 막혀 있어, 이 환경 안에서는 실제 API 응답을 직접 테스트하지 못했습니다.
> 대신 요청/응답 형식은 국토교통부 공식 문서 기준으로 작성했고, `npm run build`로 코드 자체는
> 정상적으로 컴파일되는 것까지 확인했습니다. 실제 데이터 연동은 로컬 PC에서 `npm run dev`로 처음
> 실행할 때, 또는 배포 후 확인하시면 됩니다. 만약 첫 실행에서 오류가 나면 화면의 에러 메시지를
> 그대로 알려주시면 바로 고쳐드릴게요.

## 폴더 구조

```
app/
  page.tsx            첫 화면 (Dashboard 컴포넌트 렌더링)
  api/update/route.ts "지금 업데이트" 버튼이 호출하는 서버 API
  globals.css          디자인 토큰 및 전체 스타일
components/
  Dashboard.tsx        지도 개념도 + 랭킹 + 지역 리스트 UI
lib/
  regions.ts           부산 16개 + 울산 5개 구·군 지역코드·좌표
  molit.ts             국토교통부 실거래가 API 클라이언트
  trend.ts             이번 달 vs 지난 달 가격 추세 계산 로직
```

## 다음 단계

1. `.env.local`에 두 키를 채우고 `npm run dev`로 실제 데이터가 정상적으로 뜨는지 확인
2. 지도를 개념도가 아니라 실제 카카오맵으로 바꾸고 싶다면 `KAKAO_JS_KEY` 연동 단계 진행
3. Vercel(무료)에 배포해 실제 주소로 접속 가능하게 만들기
4. 경남 지역 추가(선택) — `lib/regions.ts`에 지역코드만 추가하면 됨
